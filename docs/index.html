Generative Architecture Overview

FareSynth AI leverages a multi-network Time-series Generative Adversarial Network (TimeGAN) specifically designed to model sequential airline pricing and booking dynamics. Unlike standard GANs that capture only static feature distributions, TimeGAN simultaneously learns cross-sectional correlations and stepwise transition probability densities over multi-day departure windows.

TimeGAN Multi-Network System

The framework combines an Autoencoder (Embedding & Recovery networks) with an Adversarial Framework (Generator, Discriminator, and Supervisor). The Supervisor network captures the stepwise temporal transition dynamics: \(H_t = s(H_{t-1})\), ensuring realistic autocorrelation, seat spoilage constraints, and booking curves across the 30-day departure horizon.

1. Embedding Network: \(\mathcal{E}: \mathcal{X} \to \mathcal{H}\) — Projects 7-dimensional sequential flight space into latent code space.
2. Recovery Network: \(\mathcal{R}: \mathcal{H} \to \tilde{\mathcal{X}}\) — Reconstructs original flight sequences from latent representations.
3. Sequence Generator: \(\mathcal{G}: \mathcal{Z} \to \mathcal{E}\) — Maps Gaussian noise \(Z \sim \mathcal{N}(0, 1)\) into synthetic latent representations.
4. Sequence Supervisor: \(\mathcal{S}: \mathcal{H}_{1:t-1} \to \mathcal{H}_t\) — Enforces stepwise temporal autoregressive dynamics.
5. Discriminator: \(\mathcal{D}: \mathcal{H} \to [0, 1]\) — Evaluates realism of hidden trajectory representations.
